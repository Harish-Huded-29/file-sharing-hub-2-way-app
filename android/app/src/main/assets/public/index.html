❓ How to Use (Host)

1

Connect Network

Connect your phone to a Wi-Fi Router or turn on your Mobile Hotspot. No internet is required.

2

Custom User Name

Tap ✏️ Change User Name to set any custom offline name (e.g. immortal.local) for easy access across Windows, Linux and Mac.

3

Choose Files

Tap 📂 Choose Files to select the files you want to share with others.

4

Start Server

Press ▶️ Start Server to launch the server. It will display your custom Access URL.

5

Client Access

Have users open your link name (e.g. name.local:8080) or IP URL on their browser. They must be on the same local network.

🔒

Secure Cache Cleanup

For your storage safety, all uploaded and shared data is kept in temporary cache. As soon as you stop the server or swipe the app away, all files are permanently deleted from your device. No memory leaks!

ℹ️ Local DNS Compatibility

1

Windows, Mac, Linux & iOS Support

All these operating systems have built-in Local DNS / mDNS support. They resolve offline names like username.local:8080 seamlessly without internet.

2

Why Android Won't Work with Local DNS

Android OS does not support Local DNS resolution in mobile browsers (such as Chrome). Android strictly queries public internet DNS servers, so offline domain names cannot be resolved locally on Android.

💡

Solution for Android Devices

For only Android devices, use the Direct IP link (192.168.x.x:8080) below. It connects directly with zero issues and ultra-fast transfer speeds.

✏️ Change User Name

Enter a custom username for your offline link. Peer devices will use this name to access your shared files.
